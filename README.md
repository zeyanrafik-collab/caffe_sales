# Cafe Sales Data Analysis | Python & Jupyter Notebook

This project focuses on cleaning, exploring, and visualizing cafe sales data using Python in Jupyter Notebook.

The dataset was processed using **Pandas and NumPy** to improve data quality, handle missing values, identify inconsistencies, and prepare the data for meaningful analysis.

### Key Activities
- Data inspection and understanding
- Data cleaning and preprocessing
- Handling missing and duplicate values
- Exploratory Data Analysis (EDA)
- Sales trend and product performance analysis
- Data visualization using Matplotlib and Seaborn
- Generating business insights from sales data

### Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Project Objective
To transform raw cafe sales data into clean, structured, and meaningful information through data analysis and visualization, helping identify sales patterns and business insights.

**Skills Demonstrated:** Data Cleaning | Exploratory Data Analysis | Python | Data Visualization | Business Insights
